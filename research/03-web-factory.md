# Web Factory
Mission: brief/reference/screenshot/design → functional verified responsive web experience, never a fake screenshot-as-site.

Universities: screenshot-to-code; browser-measured AI site-cloner patterns; Create Loco visual IR/causal repair/browser verification; component/design systems; Canva AI responsive experience/HTML import.

Extract: visual IR, DOM/layout/style/asset extraction, reference decomposition, component graph, responsive constraints, interaction/state model, accessibility, routes/data/API contracts, browser verification, screenshot diff, console/network checks, performance/SEO, deployment/rollback/provenance.

Failure research: looks-right-but-doesn't-work, background-image cheating, responsive collapse, fake buttons, hallucinated APIs, missing assets, hidden console errors.

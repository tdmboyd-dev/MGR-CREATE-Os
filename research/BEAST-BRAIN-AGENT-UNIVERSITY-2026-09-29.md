# BEAST Brain / Agent University — 2026-09-29

The Brain is a controller subsystem, not a model: deterministic policy + DecisionEngine/Jev + memory/retrieval + tool schemas + a replaceable generative controller + evaluation/feedback.

Research universities now required: BFCL V4 for tool/function calling; ToolSandbox for stateful tool use and state dependencies; tau3-bench for realistic agent/user/tool workflows; LongMemEval-V2 for long-term agent memory; Qwen3-8B as an economical pilot candidate with larger/frontier models kept as comparison candidates.

Promotion rule: no model is promoted from training loss, card count, parameter count or synthetic scores. It must beat protected baselines on executed MGR evals, preserve authorization boundaries, show latency/cost evidence and have rollback.

Portable controller contracts move toward MGR-API-MCP. MGR Agents remains a reference consumer. Creation OS remains the creation capability/control plane.

# MGR Production Brain 1

This is a substantive executable extension of the earlier planning/catalog prototype. It is not completion of the entire studio vision.

The host agent turns natural language into explicit production inputs. Packaged Node tools preserve standalone project history and assets, inspect a supported media subset, check declared camera geometry, assemble editorial cuts and generate working single-page content websites. Existing prompt compilation and research retrieval remain available.

Research lives inside the plugin: competitor and production dossiers, source/claim catalog, and new implementation packets for storage, asset inspection, camera geometry, editorial assembly and motion websites. Each new packet states its methods, alternatives, license scope, runtime, failure cases and acceptance criteria. It does not mark all 75 broader tracks complete.

Runtime: Node 24.21+ with node:sqlite and filesystem access. This release does not provision a hosted MGR MCP server. Higgsfield and YouArt remain optional configured connections whose authentication and tool availability must be checked in the active host. No provider calls or paid generation were made.

The tests and workflow exercise are in evidence/. The website's browser acceptance, OTIO/NLE round trip, broader rendering/DCC implementations, neural identity control, production-grade media ingest and rendered-quality benchmark remain unverified or unimplemented. Headless Edge failed before returning DOM in this environment. These are material gaps, not completed features.

Creation OS receives reusable source and research through the existing review branch. Presence on that branch is not application integration, a merge, deployment or production certification.

## Exact runtime behavior

1. Atomically bind one request key/principal to a normalized exact JSON plan, plan digest, versioned run and all stage identities. Reject a changed same-key plan. The existing migration ledger records project-runtime-v1; repeated opens preserve its timestamp and an older runtime refuses a newer reserved version. Failed initialization rolls back partial schema. Legacy unowned rows are not silently assigned to the current actor.
2. Scope every lookup and stable execution identity to the host tenant/workspace/actor. Plans cannot choose another principal. Managed run/stage mutations use the project commands; generic save calls cannot bypass checkpoint custody. Snapshot data, digests and required stage/result bindings are validated before recovery.
3. Reuse ObjectiveOrchestrator for dependency scheduling. Persist first claim before calling a factory; require original reconciliation. Competing handles cannot claim another first execution. Keep unresolved RUNNING/UNKNOWN work for reconciliation, never reset it to READY. Revision/producer fences prevent stale publication after another accepted result.
4. Persist approved outputs and events transactionally. Replay completed checkpoints rather than executing them again. Malformed or mismatched replies remain unconfirmed/recoverable, not falsely failed. A failed sibling stops undispatched work and retains any other accepted unresolved operation until its original outcome is known; no terminal project failure hides an outstanding job.
5. Preserve WAITING_APPROVAL/WAITING_RESOURCE/UNKNOWN states. The owner adapter has no approve/enroll/renew method. It previews original ONE commands, dispatches only original exact approved state, reconciles pending/unknown state, and reads original artifacts. Each call is fenced by the same trusted host authority. Scope, zero allocation, criteria, operation/workspace, actor, command/digest and artifact response binding are checked.
6. Independently check returned base64 byte length/SHA and original accepted receipt. Validate GLB v2/header/declared length after original API/native verification. Native Markdown must match the original renderer's exact requested text. Store workflow/job/hash references, not another copy of binary ownership. Caller rights declarations and these receiving checks are not legal clearance, independent Blender/engine import or artistic acceptance.
7. Cancellation stops undispatched stages. Unadmitted original workflow proposals can be cancelled locally; already accepted native work is observed through original status, never declared remotely stopped or blindly sent cancellation again. Project stays CANCELLING while its accepted work is unresolved. Existing accepted outputs survive cancellation. Graceful close drains the current call, prevents later stage dispatch, saves the wait state and closes its owned DB; it does not fabricate provider cancellation.
8. Public project reads expose scoped stage/request/progress references without producer tokens. Public bootstrap types distinguish durable and memory services. Native document/Forge request IDs from earlier permanent sessions are not rewritten. Opt-in project stage IDs use a separate run/principal scope; migrate/reconcile older custom-adapter identities explicitly rather than restarting them with new keys.
